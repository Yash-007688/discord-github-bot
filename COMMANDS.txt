Discord GitHub Bot Commands (Advanced)
=====================================

Important:
- Bot sirf GITHUB_USERNAME ka data dikhayega.
- Kisi aur username/owner ka data nahi milega.

1) /github-me
   Kaam: Aapka GitHub profile info dikhata hai.
   Includes: Name, followers, following, public repos, company, location, joined date.

2) /github-summary
   Kaam: Aapke GitHub account ka advanced summary.
   Includes: Total stars, forks, watchers, open issues, profile counters.

3) /github-repo repo:<repo-name>
   Kaam: Aapke ek specific repo ka detail.
   Includes: Stars, forks, open issues, language, visibility, default branch, last push.
   Example: /github-repo repo:discord-github-bot

4) /github-activity [limit]
   Kaam: Recent public activity list.
   Limit: 1 se 10 (default 5).
   Includes: Event type, repo name, timestamp.
   Example: /github-activity limit:7

5) /github-top-repos [limit]
   Kaam: Top repositories by stars.
   Limit: 1 se 10 (default 5).
   Includes: Repo name, stars, forks.
   Example: /github-top-repos limit:5

6) /github-languages
   Kaam: Aapke public repos me language distribution.
   Includes: Top languages + kitne repos us language me hain.

Setup Commands (Terminal)
=========================

A) npm install
   Kaam: Dependencies install karta hai.

B) npm run register
   Kaam: Discord slash commands register/update karta hai.

C) npm start
   Kaam: Bot + webhook server start karta hai.

Webhook Endpoint
================

POST /github-webhook
Kaam: GitHub events Discord channel me embed format me bhejta hai.
Supports: push, pull_request, issues (+ generic fallback).
