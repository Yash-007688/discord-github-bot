Discord GitHub Bot Commands (Pro)
=================================

Core Commands
-------------
/github-me
/github-summary
/github-repo repo:<name>
/github-activity [limit]
/github-top-repos [limit]
/github-languages

Advanced Commands
-----------------
/github-streak [username]
/github-leaderboard
/github-chart repo:<name> [owner]
/github-trending [limit]
/github-compare user1:<name> user2:<name>
/github-readme repo:<name> [owner]

Auto Features
-------------
- Slash commands auto-register on startup
- Status rotation:
  - Watching GitHub
  - Tracking Repos
  - Monitoring Commits
- Webhook security verification
- Auto reconnect fallback
- Anti-crash protection
- JSON DB tracking in data/stats.json

Setup
-----
1) npm install
2) npm start

Webhook endpoint (local):
POST /github-webhook

Vercel endpoints:
- /interactions
- /github-webhook
